# awesome config

Extra bindings:

- `Mod+R` dmenu run
- `Mod+O` jump to window by name
- `Mod+Up` / `Mod+Down` volume
- `Mod+D` move window under mouse
- `Mod+T` toggle on top

All extra bindings are docsumented in `Mod+S`

## Tabs

Windows can be stacked into tabs to combine many windows into one virtual window.

- `Mod+G`, keep holding `Mod`, click windows to pull them into the focused window's stack (outlined in green), release `Mod` when done
- `Mod+Shift+Enter` open a terminal as a new tab on the focused window
- `Mod+[` / `Mod+]` previous / next tab
- `Mod+Shift+G` detach focused window from its stack
- Click or scroll the tab bar to switch tabs
- Drag the current tab to move the stack
- `Mod`+drag a tab to pull it out
- Middle-click a tab to detach it
